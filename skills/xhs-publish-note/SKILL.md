输入（由用户在对话里提供）：

- 笔记类型：图文 或 视频
- 标题、正文
- 话题（可选）
- 图片/视频路径（本机绝对路径优先）
- 图标/配图需求（可选）：关键词、风格（扁平/拟物/线性）、主色、是否透明背景

相关技能（安装导航）：

```bash
clawhub install xhs-suite
```

素材准备（可选，省去用户自己找图标/配图）：

1. 让用户只给“需求描述”，例如：
- “一个红色爱心线性 icon，透明背景”
- “适合美妆笔记的浅色系贴纸风小图标”
- “增长/数据/上升箭头 icon，极简风”
2. 调用 `agent-browser` 去搜索并挑选合适素材：
- 优先选择明确可商用/可复用的来源（例如免版权图库/开源图标库）
- 打开素材大图或预览页，确保清晰度足够
3. 用 `agent-browser` 直接截图保存到本地（避免下载链路不稳定）：
- 建议路径：`data/assets/<YYYY-MM-DD>/icons/<name>.png`
- 同时记录来源 URL 到：`data/assets/<YYYY-MM-DD>/sources.txt`
4. 在进入发布页前，把最终选中的图片路径回填到“媒体上传”步骤里。

提示：如果需要多套备选，建议一次性截图 3-5 个候选，再由用户选最终版本。

流程：

1. 要求用户先完成 `/xhs-login-cookies`，否则先走登录。
2. 调用 `agent-browser` 打开发布页面（根据当前小红书后台路径，允许页面变化）。
3. 上传媒体：
- 图文：选择多张图片
- 视频：选择视频文件 + 封面（如需要）
4. 填写标题/正文，插入话题。
5. 明确人工确认点：在点击“发布/提交”前，暂停并让用户确认最终预览。
6. 发布后：
- 获取发布结果页 URL 或提示信息
- 如失败，截图并记录错误文案

约束：

- 不在本仓库实现 DOM 自动化细节；只给出可执行的人工/半自动步骤。
- 涉及文件选择弹窗的步骤，由 `agent-browser` 处理。
